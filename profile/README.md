# cyclehabits

App to help you build and track daily habits — vitamins, workouts, and routines — with a simple and focused experience.

## Stack

- **Frontend:** React, Vite, TypeScript, Tailwind CSS
- **Backend:** Firebase
- **Infrastructure:** Cloudflare
